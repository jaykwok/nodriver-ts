# Local socket / Windows named pipe

[简体中文](zh-CN/mcp-socket.md)

`--mcp-transport socket` or `nodriver-ts/mcp/socket` provides a long-running local IPC service: a Unix domain socket on Linux and a local named pipe on Windows. It shares the 26 default tools, application leases, browser pool, resources and cancellation behaviour with the other entry points, and supports only MCP 2026-07-28. This is a custom transport that needs the matching client; ordinary MCP clients should use stdio or HTTP.

The service uses the official SDK's `serveStdio(factory, { transport, legacy: 'reject' })` and `StdioServerTransport`, reusing their UTF-8 NDJSON framing, protocol discovery, subscriptions and cancellation. For the framing, see [MCP custom transports](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports); for path formats, see [Node IPC](https://nodejs.org/api/net.html#ipc-support).

## Starting the server

First set a random `NODRIVER_MCP_TOKEN` (at least 32 characters):

```sh
npm run build
node dist/mcp/cli.js --mcp-transport socket
```

The service runs in the foreground and writes the actual path to stderr; stdout carries no logs or credentials. A random path is generated by default. `--socket-path PATH` can name an absolute path inside an existing private directory on Linux, or a local `\\.\pipe\nodriver-NAME` on Windows. `--token-env` changes the name of the environment variable holding the token, and Chrome launch options are the same as in [MCP](mcp.md).

- **Linux**: the parent directory must be owned by the running user, grant no group or other permissions, and not be a symbolic link. The socket's mode is 0600. The default temporary directory is 0700 and is deleted on close. The path is at most 100 UTF-8 bytes. An existing file or socket is never replaced; leftovers from a crash must be checked and handled by the caller.
- **Windows**: only local paths with the `\\.\pipe\nodriver-` prefix are accepted, never remote pipes. The system default pipe ACL is used, and token authentication is enforced on top of it. There is no cross-user sandbox.

Closing is idempotent: when listen fails, the endpoint that never listened is not closed twice, and a socket that was already destroyed is not destroyed again.

## Client

```ts
import { Client } from '@modelcontextprotocol/client';
import {
  startBrowserMcpSocketServer,
  BrowserMcpSocketClientTransport,
} from 'nodriver-ts/mcp/socket';

const token = process.env.NODRIVER_MCP_TOKEN!;
const service = await startBrowserMcpSocketServer({ tokens: { [token]: 'local-operator' } });
const transport = new BrowserMcpSocketClientTransport({ path: service.path, token });
const client = new Client(
  { name: 'local-agent', version: '1' },
  { versionNegotiation: { mode: { pin: '2026-07-28' } } },
);
try {
  await client.connect(transport);
  console.log((await client.listTools()).tools);
  const leaseId = transport.leaseId; // save it to reconnect explicitly; reconnecting also needs the token
} finally {
  await client.close();
  await service.close();
}
```

See `examples/mcp-socket.ts` for a full example. `leaseId` is bound to the principal that the provisioned token maps to; clientInfo is not trusted, and one principal cannot use another's leases. Closing the client cancels that connection's in-flight requests, while the browser and refs remain until an explicit `browser_close`, lease release or idle expiry. Reconnecting must authenticate again and pass `leaseId`; there is no automatic reconnect or action replay.

A trusted host can inject an existing `BrowserSessionManager` and call `manager.release(principal, leaseId)` to release a lease immediately. Closing the service also closes an injected manager, so hosts that share a manager should coordinate shutdown. Lifecycle rules for leases, the pool and owned or external browsers are described in [MCP over HTTP](mcp-http.md).

## Authentication preamble

The first line of a connection is an application authentication preamble, not an MCP method:

```json
{
  "type": "nodriver-auth",
  "token": "provisioned random secret",
  "leaseId": "optional existing lease"
}
```

On success the service replies with one line, `{"type":"nodriver-auth","leaseId":"..."}`, and after that only standard NDJSON JSON-RPC is exchanged. Omitting `leaseId` creates a lazy lease, and Chrome is not launched at that point. A failed authentication closes the connection without echoing credentials. The preamble may be split across packets, or arrive together with the first MCP message. The token travels in plain text over local IPC, so do not use this for remote connections or untrusted tenants.

## Limits

| Default                | Scope                                                    |
| ---------------------- | -------------------------------------------------------- |
| 32                     | Connections, including unauthenticated ones              |
| 4 KiB / 5 s            | Authentication preamble size and deadline                |
| 16 / 4                 | Outstanding requests / subscriptions per connection      |
| 256 KiB / 128 messages | Input message buffer / messages waiting to be dispatched |
| 8 MiB / 60 s           | Output buffer / write deadline                           |
| 8 MiB                  | Maximum response size accepted by the client             |
| 30 s / 30 min          | Browser operation deadline / lease idle reclamation      |

A duplicate in-flight request ID, exceeding capacity, invalid NDJSON and writes that are too slow all close the connection. Apart from protocol notifications, no arbitrary CDP events are written to the stream.

Cancellation uses `notifications/cancelled`, and EOF on a connection aborts all of its requests. Side effects that already happened cannot be undone, and different connections are still coordinated by the same browser write queue. Resource updates are filtered by the SDK's `subscriptions/listen`; the old `resources/subscribe` is not supported. Notifications and responses in the same batch are dispatched in the order received, so the SDK's async progress callbacks run before the request completes.
