以上是控制器观测。发送→接收包含 Chrome 计算/序列化、传输、OS 调度及字符串回调前解码。分派包含 Connection JSON 解析、验证和响应交付；分派后包含过滤/ref 转换、微任务和密码保护等额外 DOM 请求，不是纯转换 CPU 时间。观测器额外解析 JSON、计算字节；10000 按钮时其中位成本为 Pipe 64.44 ms / WebSocket 86.64 ms，计入总耗时但独立于分派。字节不含分帧，各阶段中位数不一定相加为总耗时中位数。不能据此分离 Chrome 内部计算与传输/序列化。

10000 按钮的 Pipe 原始完整树为 645.82 ms / 13,612,812 字节；depth=1 为 356.03 ms / 7,137,890 字节，depth=2 为 523.07 ms / 11,011,057 字节，两者都漏掉深层按钮。partial 为 3.29 ms / 75,200 字节（6 节点），同样不完整。无过滤 root query 在该简单页面为 7.22 ms / 3,619 字节（8 节点），保留深层按钮。生产 root 快照只输出 3 个语义节点，仍读取完整 13.6 MB。

`npm run bench:ax-subtree` 在四种 frame 和 closed shadow host 上继续差分：主 frame、同进程 root 与完整树转换结果一致，跨进程和嵌套 frame 在两种传输中均超过 1 秒实验期限；此前差分在 30 秒后超时。实验在 wire 上替换命令，因此错误仍显示 Connection 原队列中的 getFullAXTree。这不代表所有 root query 都失败，但否定了通用替换。保留完整读取、root/frame 校验、generation/ref 生命周期和分页，不把部分结果伪装成完整快照。按需展开需要 Accessibility.enable 与独立的完整性/生命周期契约。
